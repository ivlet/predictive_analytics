# Лабораторная работа №3: классификация временных рядов и прогнозирование метеоданных

## Состав архива

- `notebooks/Lab3_weather_timeseries_solution.ipynb` — основной Jupyter Notebook с полным пайплайном: загрузка, EDA, feature engineering, классификация климатического типа, прогнозирование температуры на 30 дней, интеграция этапов.
- `data/raw/` — исходные parquet-файлы по шести городам за 2019–2025 годы.
- `outputs/figures/` — сохранённые графики из ноутбука.
- `outputs/tables/` — сохранённые таблицы с результатами EDA, классификации и прогнозирования.
- `requirements.txt` — зависимости.
- `docs/assignment_lab3.docx` — исходное задание.

## Краткая логика решения

1. Данные объединяются в единый часовой датасет и дополнительно ресемплируются до дневной частоты.
2. Для классификации заданы 3 климатические зоны, по 2 города в каждой:
   - умеренно-континентальная / северо-западная: Москва, Санкт-Петербург;
   - черноморская влажная субтропическая: Сочи, Геленджик;
   - дальневосточная муссонно-континентальная: Благовещенск, Находка.
3. Классификация выполняется по годовому окну временного ряда: это устойчивее, чем 30–90 дней, потому что климатический тип проявляется через полный годовой цикл.
4. Для прогноза построены отдельные модели для каждого города. Горизонт прогноза — 30 дней, целевая переменная — среднесуточная температура.
5. В финале показан единый двухэтапный пайплайн: классификация климатического типа → выбор специализированной городской модели → прогноз на месяц.

## Интерпретация результатов

Итоговые таблицы лежат в `outputs/tables/`:

- `classification_metrics.csv` — метрики классификации на train/val/test.
- `forecast_city_metrics.csv` — MAE, RMSE, MAPE, WAPE и accuracy направления изменения по городам.
- `forecast_horizon_metrics.csv` — качество прогноза по горизонтам 1–30 дней.
- `residual_diagnostics.csv` — диагностика остатков.

Основная метрика для прогноза — MAE/RMSE. MAPE для температур около 0 °C может быть нестабильной, поэтому дополнительно рассчитан WAPE.

## Полученные результаты в готовом прогоне

Классификация климатической зоны по годовому окну дала accuracy/F1-macro = 1.00 на train, validation 2024 и test 2025. Это ожидаемо для трех крупных климатических зон и полного годового окна: сезонный профиль городов хорошо разделяется.

Качество прогноза температуры на test 2025:

| Город | MAE, °C | RMSE, °C | WAPE, % |
|---|---:|---:|---:|
| Благовещенск | 3.33 | 4.29 | 22.89 |
| Геленджик | 3.14 | 4.07 | 22.03 |
| Москва | 3.95 | 4.92 | 40.82 |
| Находка | 2.65 | 3.28 | 23.05 |
| Санкт-Петербург | 3.40 | 4.21 | 38.42 |
| Сочи | 2.65 | 3.47 | 18.10 |

Важно: для прогноза origin-окна берутся раз в 7 дней, чтобы уменьшить избыточное перекрытие почти одинаковых 30-дневных прогнозов и ускорить воспроизведение ноутбука.
