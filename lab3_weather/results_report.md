# Краткий отчет по лабораторной работе №3

## Что реализовано

1. Загрузка и объединение 42 parquet-файлов по 6 городам за 2019-2025 годы.
2. EDA: тренды, сезонность, распределения, box-plot, Q-Q plot, корреляции, выбросы, пропуски, ADF-тест.
3. Feature engineering: календарные признаки, циклические признаки, лаги, rolling-статистики, динамика температуры/давления, климатическая норма.
4. Классификация климатического типа по годовому окну.
5. Оценка классификации: Accuracy, Precision, Recall, F1, ROC-AUC OvR, confusion matrix, анализ по сезонам/городам, важность признаков.
6. Прогнозирование температуры на 30 дней вперед отдельной моделью для каждого города.
7. Оценка прогноза: MAE, RMSE, MAPE, WAPE, direction accuracy, диагностика остатков.
8. Интеграция двух этапов в единый пайплайн.

## Итоговые результаты

- Классификация климатической зоны: accuracy = 1.00, F1-macro = 1.00 на test 2025.
- Прогноз температуры на test 2025:
  - лучший MAE: Находка и Сочи, около 2.65 °C;
  - наиболее сложный город по MAE: Москва, около 3.95 °C;
  - MAPE нестабилен около 0 °C, поэтому в интерпретации использован WAPE.
