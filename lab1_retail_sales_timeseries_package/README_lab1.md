# Лабораторная работа №1

Тема: анализ и прогнозирование временных рядов на примере розничных продаж.

## Файлы

- `lab1_retail_sales_timeseries.ipynb` — основной Jupyter Notebook с решением лабораторной работы.
- `retail_sales_mock_data.csv` — исходные данные.
- `requirements.txt` — зависимости для запуска ноутбука.

## Как запустить

```bash
pip install -r requirements.txt
jupyter notebook lab1_retail_sales_timeseries.ipynb
```

## Как залить на GitHub

```bash
git init
git add lab1_retail_sales_timeseries.ipynb retail_sales_mock_data.csv requirements.txt README_lab1.md
git commit -m "Add lab 1 time series analysis"
git branch -M main
git remote add origin <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
git push -u origin main
```
